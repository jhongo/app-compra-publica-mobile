# CompraPublicCercaMobile

Aplicación móvil multiplataforma desarrollada con **.NET MAUI** (.NET 10) para el proyecto de la UISRAEL.

## Tecnologías

- .NET MAUI (.NET 10): Android e iOS
- Patrón **MVVM** con CommunityToolkit.Mvvm *(propuesto)*
- **Firebase Authentication** con inicio de sesión de Google *(en investigación)*

## Inicio rápido

```bash
git clone https://github.com/jhongo/app-compra-publica-mobile.git
cd app-compra-publica-mobile
dotnet workload install maui
dotnet restore
dotnet build -t:Run -f net10.0-android
```

Los requisitos completos del entorno están en la [guía de contribución](CONTRIBUTING.md#1-requisitos-del-entorno).
